# Frontend GoodWe

Este repositório contém o frontend do sistema de monitoramento de energia GoodWe.

## Estrutura do Projeto

- `Frontend_Goodwe/` - Aplicação Next.js principal
  - Dashboard de energia
  - Sistema de aparelhos
  - Alertas e notificações
  - Interface multilíngue (Português/Inglês)

## Como Executar

```bash
cd Frontend_Goodwe
npm install
npm run dev
```

A aplicação estará disponível em `http://localhost:3000`

## Funcionalidades

- ✅ Dashboard com gráficos de energia
- ✅ Sistema de gerenciamento de aparelhos
- ✅ Alertas e notificações
- ✅ Interface responsiva
- ✅ Suporte multilíngue
- ✅ Integração com APIs de clima
- ✅ Sistema de chat com IA

## Tecnologias

- Next.js 14
- React 18
- Chart.js
- SQLite
- CSS Modules
